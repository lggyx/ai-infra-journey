## 学习原则

1. **先建后赏**：每个模块的产出是自己的代码/笔记，不是"看过"。
2. **自上而下 + 自下而上双轮**：先跑通全栈建立地图（自上而下），再逐层拆到底层实现（自下而上）。
3. **真实验证**：笔记里的数字、跑分、报错都来自真实运行，不编造。
4. **GPU 能借就借**：小实验用 CPU/Colab，大训练用按需实例（AutoDL / Lambda / RunPod），避免被本地硬件限制卡死。
